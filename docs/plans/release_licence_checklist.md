## 2. Problem: the public HF dataset repo redistributes restricted content

`huggingface.co/datasets/Jerry9999/CultureInFigurativeLanguage` is **public and not gated** (368.5 GB,
uploaded 2026-08-19..24). Making it private failed: HTTP 403 "would exceed your private storage limit".
It contains, among others:

| Path | Size | Problem |
|---|---|---|
| `data/idioms/{en,zh,hi,ar}/...` (64 files) | small | full KB text incl. McGraw-Hill-derived English entries, IdiomKB, Chengyu cloze, Fuxi, the in-copyright Hindi dictionary, Jawaher |
| `data/hi-proverbs-cpt`, `data/train_hi*` | ~13 GB | web text + meaning tags quoting the Hindi dictionary |
| `data/train_zh*`, `data/mc4-zh-idiom-cpt`, `data/fineweb-edu-zh-chengyu-cpt` | ~170 GB | re-hosted web text (ODC-BY / OpenCSG terms) + tags quoting Chengyu cloze / Fuxi / IdiomKB |
| `data/ar-amthal-cpt`, `data/train_ar*` | ~22 GB | tags quoting Jawaher (no licence) alongside CC BY sources |
| `data/eval` | 2.9 GB | check per benchmark licence before keeping public |
| `models/qwen3p5-9b-*` (8) | 151 GB | Apache-2.0 base; fine to keep |
| `eval/` | small | eval records; fine |

The paper says restricted sources are released only as rebuild scripts and corpora only as document
IDs, so the public repo contradicts it. It is also under a personal account (double-blind risk during review).

## 3. Options (user decides)

1. Immediate stopgap: gated with manual approval (`HfApi().update_repo_settings(repo, repo_type="dataset", gated="manual")`). Reversible; still a form of distribution.
2. Make private after freeing quota: move the 8 model folders to a separate public model repo (or upgrade HF storage), then `update_repo_settings(..., private=True)`.
3. Remove restricted folders and purge history: `HfApi().delete_folder(...)` for the paths in §2, then `HfApi().super_squash_history(repo, repo_type="dataset")` (deleting in a normal commit leaves the files in git history). Irreversible; verify complete copies on lustre first.

## 4. Release plan for camera-ready

- Public: CC BY / CC BY-SA / MIT KB entries with attribution and per-entry source + licence field; our annotations (entities, typology, register/variety labels) under CC BY 4.0; IdiomAtlas-MC and symbolism probe items that quote only openly licensed entries; document IDs + idiom offsets + culture scores; all code; model checkpoints.
- Scripts only: everything marked "no" in §1 (rebuild from a user-obtained copy).
- Open items: email the Jawaher authors for a licence; check Alyah and DziriEval licences before releasing AR-Figurative; native-speaker validation before release.
